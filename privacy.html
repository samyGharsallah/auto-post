Privacy Policy

auto-post

Last updated: 9 August 2026

Summary

auto-post runs entirely on the operator's own computer. It has no server, no database and no analytics. It does not collect personal data from anyone, and it has no users other than the person running it.

What the software accesses

When the operator authorizes an account, the destination platform issues an access token. The software uses that token for two things only:

  • reading the identity of the authorized account — its id and display name — so it can confirm that a video is about to be published to the intended account;
  • uploading a video file together with its title, description and publication settings.

The software does not read the operator's followers, messages, comments, contacts, watch history or any other personal information, and it never accesses data belonging to other users of any platform.

Where data is stored

Access tokens are written to files inside the software's own folder on the operator's computer (auth/tokens/). Video files and their metadata stay on that same computer. Nothing is uploaded anywhere except to the platform the operator explicitly chose to publish to.

What is shared with third parties

Nothing. There is no third-party recipient. The only outbound network requests the software makes are to the official APIs of the destination platforms — YouTube, Facebook and TikTok — and they contain only the video and metadata being published.

Retention and deletion

Tokens remain on the operator's computer until they are deleted or expire. Deleting the files in auth/tokens/ removes them permanently. Authorization can also be revoked at any time from each platform's own security settings, which invalidates the token immediately.

Cookies and tracking

This website is a set of static pages. It sets no cookies, runs no analytics and embeds no third-party scripts or trackers.

Children

The software is not directed at children and collects no data from anyone.

Changes

This policy may be updated as the software changes. The date at the top of this page reflects the most recent revision.
